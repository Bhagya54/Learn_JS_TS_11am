3 ways to make a function 🛠️

🏷️

Normal

"Has a name tag. Everyone knows it from the start."
function add(a, b) {
  return a + b;
}
  • ✅ Works before it's written (hoisted)
  • ✅ Own this & arguments
  • ✅ Can use new
📦

Expression

"A function put inside a box (variable)."
const add = function (a, b) {
  return a + b;
};
  • ❌ Not ready until the box line runs
  • ✅ Can be nameless (anonymous)
  • ✅ Own this & arguments
  • ✅ Can use new
➡️

Arrow

"The short, lazy version."
const add = (a, b) => a + b;
  • ❌ Not ready until the box line runs
  • ✂️ Short; one-liner returns by itself
  • 🙈 No own this (borrows from outside)
  • 🙈 No arguments
  • 🚫 Can't use new

Hoisting

hi();           // ✅ works
function hi(){ console.log("hi") }

hey();          // ❌ ReferenceError
const hey = () => console.log("hey");
👈

this

const p = {
  name: "Bhagya",
  normal() { return this.name },   // "Bhagya"
  arrow: () => this.name           // undefined
};
Arrow doesn't make its own this, so don't use it as an object method.

🎯 Quick pick

🏷️
Normal → main, reusable functions
📦
Expression → store or pass a function around
➡️
Arrow → short callbacks like map, filter
